# VibeProof planning notes

I use this repository for the early planning behind VibeProof. I worked through the merchant experience, storefront review components, data model, and the separation between real reviews and generated previews here.

I keep the runnable application in [vibeproof-portfolio](https://github.com/2MilinEcom/vibeproof-portfolio). This repository contains design notes rather than an app to install.

## Built with

I planned the app around TypeScript, React Router, Prisma, and Shopify theme extensions.

## Inside the project

* `docs/architecture.md`: application architecture.
* `docs/data-model.md`: the review and merchant data model.
* `docs/build-plan.md`: the original build plan.
* `docs/product-direction.md`: the earlier product direction.

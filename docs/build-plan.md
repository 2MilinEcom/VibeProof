## Definition of first usable milestone

The first usable milestone is complete when the merchant can:

1. install the app on Spoild
2. open VibeProof in Shopify Admin
3. select a live product
4. generate labeled AI preview reviews
5. choose a palette
6. preview the social review feed
7. add the VibeProof block in the theme editor
8. see the configured preview on the product page
9. keep genuine reviews logically separate from demo data
